Strongtalk on your own computer

One small program with everything in it: the terminal workspace, the type checker, the Strongtalk → TypeScript translator, and the full graphical environment, which strongtalk web opens in your browser, offline. No runtime to install.

Choose your system

Installers for macOS, Windows and Linux are below.

All downloads ↓

macOS

macOS 11 or later, Apple silicon and Intel (one universal program).

  • Installer (.pkg) universal
  • Archive (.tar.gz) universal

The installer puts strongtalk in /usr/local/bin. It is not notarized yet: if macOS refuses to open it, Control-click the .pkg and choose Open.

Windows

Windows 10 and 11, 64-bit (also runs on Windows on ARM).

  • Installer (.exe) x64
  • Portable (.zip) x64

The installer adds Start menu entries for the workspace and the environment, and can put strongtalk on your PATH. If SmartScreen warns, choose More info → Run anyway.

Linux

Any distribution: the programs are statically linked.

  • Debian / Ubuntu (.deb) x64
  • Debian / Ubuntu (.deb) arm64
  • Archive (.tar.gz) x64
  • Archive (.tar.gz) arm64

Install a .deb with sudo apt install ./strongtalk-linux-x64.deb.

One line

Install from a terminal

macOS and Linux: downloads the right program for your machine into ~/.local/bin.

$ curl -fsSL https://volland.github.io/strongtalk/install.sh | sh

Windows (PowerShell):

> irm https://volland.github.io/strongtalk/install.ps1 | iex
Then

Three ways to use it

  1. strongtalk opens the terminal workspace. Type 100 factorial and press Return.
  2. strongtalk web opens the full environment in your browser, served from the program itself, no internet needed. strongtalk web translate opens the translator.
  3. strongtalk --to-ts file.dlt -o file.ts translates Strongtalk to TypeScript; node file.ts runs it.

All releases, checksums and release notes are on GitHub Releases. To build from source, see the README.
