The type system

Add types one method at a time. Remove them and nothing changes.

Types are written in angle brackets and checked separately from running the program. Untyped code is trusted, so a large program can be typed gradually, and the checker never alters what code does.

Plain Smalltalkruns
deposit: amount
    amount <= 0 ifTrue: [
        ^self error: 'must be positive'].
    balance := balance + amount.
    history add: amount

detect: aBlock
    self do: [:each |
        (aBlock value: each) ifTrue: [^each]].
    ^self error: 'not found'
Strongtalkruns the same, and type-checks
deposit: amount <Int> ^<Self>
    amount <= 0 ifTrue: [
        ^self error: 'must be positive'].
    balance := balance + amount.
    history add: amount

detect: aBlock <[E, ^Bool]> ^<E>
    self do: [:each <E> |
        (aBlock value: each) ifTrue: [^each]].
    ^self error: 'not found'

<Int> Protocols, not classes

A type names the messages an object understands, so unrelated classes that answer the same messages share a type.

<Self> Types that follow subclasses

Self and Instance types give subclasses the right result types without redeclaring a single method.

Array[E] Generics and blocks

Generic collections, union types and block types like <[Int, ^Bool]> cover real Smalltalk idioms.

This edition

A complete Strongtalk, rebuilt in Rust

The original ran only on 32-bit Windows. This one compiles the same language to bytecode and runs it natively on a Mac, or as WebAssembly in any modern browser.

Typed parser and compiler

The full Strongtalk syntax, type annotations included, compiled to a compact bytecode.

Bytecode interpreter

Activations live on the heap, so recursion can go very deep. Blocks support non-local return.

The whole numeric tower

SmallInteger, LargeInteger, Float and Fraction arithmetic: 100 factorial just works.

Type checker

Check a class, a method or a do-it from the browser. Errors point at the expression that failed.

ANSI exceptions

on:do:, ensure:, retry, resume:, with primitives named after the original VM's.

File-in, file-out

Strongtalk's Delta define:as: chunk format, so classes travel as plain source files.

The environment

The classic Strongtalk desktop, in a tab

A windowed, image-style environment like the original, with the VM running in a Web Worker so an endless loop never freezes the page.

  • Launcher and Transcript, multiple workspaces with Do it, Print it and Inspect it
  • Class hierarchy and outliner class browsers that compile methods as you save
  • Inspectors, debugger-style error windows and picture windows for graphics
  • Your changes are kept between visits and can be filed out as source

Lineage

A small language with a long shadow

The people and ideas behind Strongtalk went on to shape the runtimes most of us use every day.

1987–91

Self

Optimizing compilers for a pure object language at Stanford and Sun.

1993

Strongtalk types

An optional, sound type system for Smalltalk, presented at OOPSLA.

1994–96

Animorphic

A small company builds the Strongtalk system and its adaptive VM.

1997–99

Java HotSpot

Sun acquires Animorphic; the VM becomes the heart of Java.

2006 →

Open source, V8, Dart

Strongtalk is released; its team goes on to V8 and Dart.

Run it yourself

On your own machine

The source is on GitHub. Build the terminal VM or the website with Rust.

Terminal workspace

A native build with an interactive workspace, a type checker and a benchmark.

$ git clone https://github.com/Volland/strongtalk
$ cd strongtalk && npm run build:native
$ vm/target/release/strongtalk -e '100 factorial'
$ vm/target/release/strongtalk --typecheck

WebAssembly website

Needs the wasm32-unknown-unknown target and wasm-bindgen 0.2.128.

$ rustup target add wasm32-unknown-unknown
$ cargo install wasm-bindgen-cli --version 0.2.128
$ npm run build      # → dist/
$ npm test

Everything is an object. Try sending it a message.

The full environment opens in a second, with workspaces, class browsers and a type checker, all running locally in your browser.
